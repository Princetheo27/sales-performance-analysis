## sales-performance-analysis

This project analyzes sales performance using SQL CSV data.

##  Objectives

Analyze total sales
Identify top-performing products
Compare sales performance
Calculate key sales metrics
Practice SQL data analysis

SQL 
CSV
Github

Total units sold

Units sold by product 
Average unit price
Product performance ranking
Revenue by city and product

Identified total sales revenue across the dataset.

Identified products with the highest number of units sold.
